How the numbers are calculated数字是怎么算的

  • Yield % = Good ÷ Output良率 % = 良品 ÷ 产量
  • Attainment % = Output ÷ Target达成率 % = 产量 ÷ 目标
  • Utilization % = Run minutes ÷ Planned minutes利用率 % = 运行分钟 ÷ 计划分钟
  • Totals are summed across all rows in the file.所有合计都是文件中全部行的总和。
